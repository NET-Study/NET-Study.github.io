The reading experience

A page that feels like paper

Warm parchment, real serif type, generous leading. Set the text size, column width, and appearance once and the app stays quiet.

What it does

Everything for study,
nothing for distraction

Reference navigation

All 66 books with chapter grids, plus a “Go to” field that understands John 3:16, rom 8:28-39, Ps 23, and semicolon lists.

Read your way

Serif or sans, adjustable size and measure, light, dark, or system appearance, with line spacing that lets a paragraph breathe.

Highlight and note

Click a verse number to highlight in five colors, bookmark it, copy with the reference, or write a note that lives beside the text.

Saved & notes

Bookmarks and study notes collect in the sidebar and jump straight back to the passage, so a thread of thought is never lost.

Works offline

Every passage you open is cached to disk. Your recent readings and searches still work on a plane, a train, or a bad hotel Wi-Fi.

Verse of the Day

Not sure where to land? Open a verse chosen for the day, or pull a random passage and start reading.

Search

Finds what you have read, instantly

Type three or more characters that are not a reference and the app searches every cached passage. All words must match, case and accents are ignored. Arrow keys move through results; Return opens the verse and scrolls to it.

  • Nothing is sent to the network
  • Results show a snippet around each hit
  • Search still works offline

Install

Two clicks, then a lifetime of reading

macOS

Apple silicon
  1. Download the .dmg and open it.
  2. Drag NET Study into Applications.
  3. First launch: right-click → Open.

The app is ad-hoc signed, not notarized, so Gatekeeper asks once. No luck? Clear the flag:

xattr -dr com.apple.quarantine "/Applications/NET Study.app"

Requires macOS 14 or later on an M1 or newer. There is no Intel build. Prefer to compile it? ./build.sh produces an app with no quarantine prompt.

Download .dmg Source on GitHub →

Windows

Windows 10, 11
  1. Download the Setup .exe.
  2. Run it and follow the installer.
  3. Launch from the Start menu.

The installer is unsigned, so SmartScreen may warn you the first time. Choose More info → Run anyway.

No admin rights required. A portable build exists but is not published, since antivirus engines flag it.

Download .exe Source on GitHub →

Linux

Virtually all distros
  1. Clone the source code by running git clone https://github.com/NET-Study/netstudy-electron.git
  2. Run cd netstudy-electron
  3. Finally, run npm run dist:linux
